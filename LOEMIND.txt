K73 – veebirakendus (PWA)
=========================

Failid
  index.html             mäng (kõik ühes failis: graafika, mudelid, helid)
  manifest.webmanifest   rakenduse nimi, ikoonid, täisekraan, horisontaalpaigutus
  sw.js                  teenustöötaja – mäng töötab pärast esimest avamist ka ilma internetita
  icons/                 rakenduse ikoonid

Kuidas üles panna
  Pane kogu kaust K73 suvalisse HTTPS-veebimajutusse, nt:
   - Netlify Drop (app.netlify.com/drop) – lohista kaust brauserisse, saad kohe lingi
   - GitHub Pages, Cloudflare Pages, Vercel või oma server
  NB! Paigaldamine ja ilma internetita töötamine vajab HTTPS-i (või localhost).
  Otse failist (topeltklõps index.html) mäng käivitub, aga rakendusena paigaldada ei saa.

Telefoni paigaldamine
  Android (Chrome): ava link → menüü ⋮ → "Lisa avakuvale" / "Installi rakendus"
  iPhone (Safari):  ava link → Jaga → "Lisa avakuvale"

Kohalik test arvutis
  python3 -m http.server 8000   (K73 kaustas) → ava http://localhost:8000

Märkus: fondid laaditakse Google Fontsist esimesel avamisel; ilma internetita
kasutatakse varufonti, kui neid pole veel vahemälus.
